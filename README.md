# Vivek S. Shyavi — Static Portfolio

This version uses only HTML, CSS and vanilla JavaScript. It does not require React, Node.js, npm, a build step, a backend, or a database.

## Run locally
Double-click `index.html` or open it in a browser.

## Free hosting options
- **GitHub Pages**: best if you are comfortable using GitHub. Create a public repository, upload these files to its root, then enable Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
- **Netlify**: easiest drag-and-drop option. Sign in, open the manual deploy/drag-and-drop area, and upload the extracted project folder. Netlify provides a free `*.netlify.app` subdomain.
- **Cloudflare Pages**: another free static hosting option, suitable if you later want Git-based deployment.

Free plan limits and terms can change. A custom domain (for example, `yourname.com`) usually costs extra; the free provider subdomain is enough to start.

## Before publishing
1. Confirm contact details and LinkedIn URL.
2. Review project descriptions for accuracy and confidentiality.
3. Add a GitHub link only if you want it public.
4. Check that the “open to opportunities” line reflects your availability.
5. Add a resume PDF only after you are happy to make it publicly downloadable.

## Update the site
Edit `index.html` for text, `styles.css` for appearance and `script.js` for menu/scroll behavior. Save and refresh your browser. When hosted, upload/push the updated files again.


## Profile photo
The hero portrait is stored at `assets/profile.jpg`. Replace that file with your preferred portrait using the same filename to update the photo.
